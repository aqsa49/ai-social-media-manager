# AI Social Media Manager 🚀

An AI-powered social media automation platform that helps users generate engaging posts, schedule content, and manage multiple social media platforms from a single dashboard.

## 📌 Features

- ✨ AI-powered caption generation
- 📅 Post scheduling system
- 🌐 Multi-platform support (Twitter, LinkedIn, Instagram-ready structure)
- 💾 SQLite database for storing posts
- ⚡ FastAPI backend with REST APIs
- 🎨 Simple frontend dashboard (HTML/CSS/JS)
- 📊 View scheduled and published posts

## 🧠 How It Works

1. User enters a topic and selects a platform  
2. AI generates a high-quality post caption  
3. Post is saved in the database  
4. Scheduler can publish posts at defined times  

## 🏗️ Tech Stack

- Backend: FastAPI, Python
- Database: SQLite + SQLAlchemy
- Frontend: HTML, CSS, JavaScript
- AI: Rule-based generator (upgradeable to OpenAI API)
- Deployment: GitHub Codespaces / Render / Railway
